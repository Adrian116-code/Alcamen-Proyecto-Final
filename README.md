🚀 Instalación y Configuración
Requisitos Previos
Tener instalado Android Studio.

JDK 17 o superior configurado en el entorno.

Un emulador configurado en el Android Virtual Device Manager (AVD) o un dispositivo físico conectado mediante depuración USB (Android 7.0 / API 24 mínimo).

Pasos para Ejecutar
Clonar el repositorio:

Bash
git clone "https://github.com/Adrian116-code/Alcamen-Proyecto-Final"

Abrir el proyecto en Android Studio:

Inicia Android Studio.

Selecciona Open y navega hasta la carpeta del proyecto clonado.

Sincronizar Gradle:

Permite que Android Studio descargue las dependencias y sincronice los archivos Gradle (Sync Project with Gradle Files).

Ejecutar la App:

Selecciona tu emulador o dispositivo físico en la barra de herramientas superior.

Haz clic en el botón de Run (Shift + F10).

🧪 Generación del APK
Si deseas compilar la aplicación para generar un paquete ejecutable (APK) de pruebas:

Ve al menú superior en Android Studio: Build > Build Bundle(s) / APK(s) > Build APK(s).

Una vez completado el proceso, la ruta por defecto del ejecutable generado estará en:

app/build/outputs/apk/debug/app-debug.apk
